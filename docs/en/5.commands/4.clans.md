More about clans under [Clans](/guides/clans).

## Find clans

- `/clans`: open the clan directory
- `/clans list`: show the directory
- `/clans search <text>`: search for a clan
- `/clans info <clan>`: information

## Join and found

- `/clan invitations`: your invitations
- `/clan accept <clan>`: accept an invitation
- `/clan decline <clan>`: decline an invitation
- `/clan apply <clan> [text]`: apply
- `/clan withdraw <clan>`: withdraw an application
- `/clan join <clan>`: join an open clan
- `/clan create <tag> <name>`: check tag and name
- `/clan found <tag> <name>`: found a clan

## Members

- `/clan`: open your clan
- `/clan info`: show your clan
- `/clan members`: show members
- `/clan leave`: leave the clan
- `/clanchat` or `/cc`: clan chat
- `/clan help`: all actions

## Officers

- `/clan invite <player>`: invite
- `/clan uninvite <player>`: withdraw an invitation
- `/clan applications`: show applications
- `/clan applications accept <player>`: accept an application
- `/clan applications decline <player>`: decline an application
- `/clan kick <player>`: remove a member
- `/clan bans`: show clan bans
- `/clan unban <player>`: lift a ban
- `/clan log`: clan log
- `/officerchat` or `/oc`: officer chat

## Founder

- `/clan promote <player>`: promote
- `/clan demote <player>`: demote
- `/clan rename <name>`: change the name
- `/clan tag <tag>`: change the tag
- `/clan colour aqua|mint|rosa|orange`: change the colour
- `/clan mode invite-only|request|open`: change how players join
- `/clan description [text]`: set the description
- `/clan members-public on|off`: show or hide the member list
- `/clan transfer <player>`: hand over founding
- `/clan disband`: disband the clan

Add `confirm` at the end to run actions without asking.
