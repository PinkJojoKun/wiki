More about the mode under [Creative](/game-modes/creative). Instead of `/plot` you can use `/p`.

## Get a plot

- `/plot auto`: get the next free plot
- `/plot claim`: claim the plot you stand on
- `/plot home`: go to your plot

## Visit plots

- `/plot visit <player>`: visit a plot
- `/plot list`: list plots
- `/plot info`: plot information
- `/plot middle`: go to the middle
- `/plot like` and `/plot dislike`: rate

## Manage your plot

- `/plot add <player>`: let someone build while you are online
- `/plot trust <player>`: let someone build even while you are offline
- `/plot remove <player>`: take permissions away
- `/plot deny <player>`: ban from your plot
- `/plot kick <player>`: kick off your plot
- `/plot flag set <flag> <value>`: set a flag
- `/plot flag list`: list flags
- `/plot set floor|wall|border`: change the look
- `/plot clear`: reset
- `/plot delete`: give up

## WorldEdit

- `//pos1` and `//pos2`: set corners
- `//set`, `//replace`, `//walls`, `//overlay`: edit
- `//copy`, `//cut`, `//paste`, `//rotate`, `//flip`: copy
- `//stack`, `//move`, `//smooth`: change
- `//sphere`, `//cyl`, `//pyramid`: shapes
- `//undo` and `//redo`: undo

More under [WorldEdit](/game-modes/creative/worldedit).
