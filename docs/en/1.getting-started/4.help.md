## In-game guide

`/guide` or `/help` opens the guide. It has these pages:

- First steps
- Game modes
- Together
- Settings
- Help

The in-game sidebar reminds you: “New here? /guide”.

## Report a bug

Found a bug? Type `/bug`.

1. Choose a category: gameplay, connection, performance, interface, security or other.
2. Enter a title and a description. The game adds your position and version itself. Do not include passwords or other secrets.
3. You get a code such as `BUG-123`.

If sending does not work right away, the game tries again.

`/bugs` shows your reports with their status: new, confirmed, in progress, fixed, duplicate or closed. When the team replies, you get a message. You also see your reports on the website.

## Report a player

Someone is breaking the [rules](/reference/rules)? Type `/report <player>` or click their message in chat.

1. Choose what happened.
2. Tick the messages you saw.
3. Optionally add a description.
4. Click **Send report**.

You get a confirmation once the report has arrived. Only report real rule breaks. False reports are forbidden.

## Discord

The [official Discord](https://discord.sirargon.net) has news, help with getting started and people to play with.

## Cannot connect?

- Check your Minecraft version: 26.3 or 26.2.
- Enable server resource packs.
- If the network is under maintenance, the game tells you when it reopens.
- If all lobbies are full, you wait in a queue. `/leavequeue` leaves it.
