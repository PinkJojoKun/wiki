## Mitbauer

- `/plot add <Spieler>` lässt jemanden bauen, solange du online bist.
- `/plot trust <Spieler>` lässt jemanden auch bauen, wenn du offline bist.
- `/plot remove <Spieler>` nimmt die Rechte wieder weg.

## Sperren

- `/plot deny <Spieler>` sperrt jemanden von deinem Plot aus.
- `/plot kick <Spieler>` wirft jemanden von deinem Plot.

## Flags

`/plot flag set <Flag> <Wert>` ändert Einstellungen deines Plots, zum Beispiel:

- Zeit und Wetter
- Begrüßung und Abschied
- Musik
- ob Besucher etwas benutzen dürfen
- Redstone, Wasser und Lava
- Wachstum, Schmelzen und Verfall

`/plot flag list` zeigt alle Flags.

## Aussehen

`/plot set floor|wall|border` ändert Boden, Wand oder Rand.

## Zurücksetzen

- `/plot clear` setzt deinen Plot zurück.
- `/plot delete` gibt deinen Plot frei.
