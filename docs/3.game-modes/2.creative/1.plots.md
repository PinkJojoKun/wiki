## Plot holen

- `/plot auto` gibt dir den nächsten freien Plot.
- `/plot claim` holt den Plot, auf dem du stehst.
- `/plot home` bringt dich zu deinem Plot.

Statt `/plot` geht auch `/p`.

## Andere Plots

- `/plot visit <Spieler>` besucht den Plot eines Spielers.
- `/plot list` zeigt Plots.
- `/plot info` zeigt Infos zum Plot.
- `/plot middle` bringt dich in die Mitte des Plots.

## Bewerten

- `/plot like` gibt einem Plot ein Like.
- `/plot dislike` gibt ihm ein Dislike.
